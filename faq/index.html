FAQ

Frequently asked questions about Folio CV.

These answers explain how Folio CV works, what is included in Basic, what Pro unlocks, how export behaves, and how to think about privacy when entering resume content in a browser-based builder.

Is Folio CV free?

Yes. Folio CV is free to use for creating a resume or CV, previewing it, changing templates, customizing the design, and exporting the finished document as a PDF. No credit card is required for the core workflow.

Do I need to create an account?

No account is needed for Basic. Login access is part of Folio CV Pro, because saved CVs, AI tools, and the application tracker need an active subscription.

What is included in Folio CV Pro?

Pro includes login access, saved CV versions, AI Judge, AI tailoring, AI application writing, and the application tracker. Weekly, monthly, and yearly billing options are available on the pricing page.

Which Pro plans are available?

Folio CV Pro has three subscriptions: weekly for EUR 2.99, monthly for EUR 9.90, and yearly for EUR 79.90. All three plans unlock the same Pro workspace. The difference is only the billing period.

Can I log in without a Pro subscription?

The intended product rule is no. Basic works without login. Login belongs to Pro because saved CVs, AI tools, and the application tracker need an active subscription and a persistent account.

Who handles payment details?

Secure checkout should handle payment details, billing details, invoices, and subscription creation. Folio CV should not collect card information in its own UI. The app only needs the checkout result and subscription events to know whether Pro access is active.

What happens when Pro is canceled?

Pro should remain available until the paid billing period ends. After that, login-only features lock again while the free Basic builder remains open. Billing changes, invoices, payment methods, and cancellations should go through a hosted billing portal.

Is Folio CV suitable for ATS systems?

Folio CV templates are built with clear sections and readable information hierarchy, which can help applicant tracking systems and recruiters understand the document. ATS behavior can vary between employers and software providers, so users should still review the final PDF and keep important details written as normal text.

What file formats can I export?

Folio CV focuses on PDF export. PDF is widely used for job applications, email attachments, recruiter submissions, and upload forms where the document layout should remain stable.

Can I use Folio CV on mobile?

Folio CV can be opened in a web browser, including on mobile devices. For detailed editing, preview review, and PDF checking, a larger screen may be more comfortable because resumes contain structured information and page layout decisions.

Can I customize the design?

Yes. Users can adjust templates, fonts, colors, accents, sidebars, dividers, backgrounds, and related visual settings while reviewing the live preview. The design controls are meant to make the resume feel polished without requiring design software.

Which templates are available?

Folio CV includes modern, classic, creative, minimal, executive, mono, atlas, studio, compact, and grid resume layouts. Users can switch between templates without re-entering the same resume content.

What languages can I write my CV in?

You can write your resume content in the language you choose, as long as the text is entered into the editor fields. The exported PDF reflects the content you provide, so users can prepare resumes for different language contexts when needed.

How does Folio CV handle my data?

Folio CV is designed as a lightweight browser-based CV builder. Resume content is entered during the editing session so the tool can show a preview and create the PDF. Because resumes include personal information, users should review what they enter and check the exported file before sharing it.

Can I update my CV later?

You can return to the builder and create or edit resume content again. If you need a long-term archive, keep a copy of your exported PDF and any source details you want to reuse.

Is Folio CV only for resumes?

Folio CV is primarily for resumes and CVs. It works for job applications, freelancer profiles, student resumes, early-career applications, and experienced professionals who want a structured application document.

Folio CV Basic is free. Pro requires an active subscription.
