Features

Folio CV features for building a clear resume online.

Folio CV starts with a free Basic builder for writing, designing, previewing, and exporting a CV. Pro adds the account layer: login access, saved versions, AI feedback, AI tailoring, application writing, and a tracker for active job searches. The product is structured this way so users can test the builder first and upgrade only when they need a persistent workspace.

Live Preview

The live preview shows the resume as it is being built, so every change to the content or design can be checked immediately. This helps users understand how their personal details, work experience, education, skills, and languages fit together on the page before they export the final document. Instead of guessing how a resume will look after download, users can review spacing, hierarchy, and structure while they work.

Templates

Folio CV includes multiple CV and resume templates for different application styles. Users can switch between modern, classic, creative, minimal, executive, mono, atlas, studio, compact, and grid layouts without re-entering their content. This makes it easier to compare a conservative resume, a compact one-page format, a sidebar profile, or a more editorial portfolio-style layout.

Design Customization

The design controls let users adjust the visual direction of their resume without editing CSS or working in a design tool. Fonts, accent colors, sidebar colors, dividers, page colors, and related styling choices can be tuned while the live preview stays visible. The goal is to give enough control for a polished result while keeping the workflow simple for job seekers.

PDF Export

When the resume is ready, Folio CV exports the finished document as a PDF. PDF export is useful for job applications, portfolio submissions, email attachments, and LinkedIn workflows where a stable document format is expected. The templates are designed around an A4 preview, so users can review the page before downloading it.

Basic Without Registration

The Basic builder can be used without creating an account. Users can start writing immediately, test templates, adjust the design, and export a PDF without signing up. Login is intentionally reserved for Pro, because saved work, AI usage, and application tracking depend on an active subscription.

Free Core Workflow

Creating a resume, switching templates, customizing the design, using the live preview, and exporting a PDF do not require payment. No credit card is needed to start building a CV. Pro is the paid upgrade for account-based tools, not a gate in front of the basic document builder.

GDPR And Data Handling

Folio CV is designed as a lightweight browser-based CV builder. The resume content is entered by the user during the editing session and used to generate the preview and export. Because CVs contain personal information, users should only enter details they are comfortable using in an online tool and should review the exported PDF before sending it to employers.

What belongs where

Basic is for the finished PDF. Pro is for the job-search workspace.

The feature split should feel obvious before someone pays. Basic gives enough value to create a real document. Pro is for people who are actively applying, managing multiple CV versions, and using AI support across roles.

AI Judge

Pro can review a CV against recruiter-friendly criteria such as clarity, completeness, structure, evidence, and role fit. The goal is to show what should be improved before the user sends the document.

AI Tailoring

Users can adapt a CV toward a specific job ad without rewriting the entire document from scratch. The workflow should keep the user's real experience intact while improving wording, emphasis, and relevance.

Application Writing

Pro can produce supporting application text from the CV and job ad: cover letter drafts, motivation answers, and concise application emails that are ready to review and adjust.

Saved Versions

A logged-in Pro workspace gives users a place to keep role-specific CV versions. This matters when one application needs a compact CV and another needs more project detail.

Application Tracker

The tracker helps users remember where they applied, which role each CV was tailored for, and what stage comes next. It turns Folio CV from a document tool into a lightweight job-search workspace.

Subscription Gate

When someone clicks a Pro action, Folio CV explains pricing first. The app should not ask for an email in its own dialog before plan selection; secure checkout handles the billing step.

Product principles

The app should feel useful before it asks for money.

No payment form inside the app

Folio CV should redirect Pro customers to secure checkout. That keeps card handling, invoices, payment methods, and subscription status outside the app instead of rebuilding billing screens from scratch.

Clear upgrade moment

Free actions open the builder. Pro actions open pricing. This creates a simple rule for users: build and export for free, then subscribe when saved work, AI, or tracking becomes necessary.

Folio CV Basic is free. Pro adds the logged-in workspace.
