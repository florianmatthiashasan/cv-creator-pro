How it works

Start with the free CV builder. Move to Pro when you need an account.

Folio CV separates document creation from account features. You can write, design, preview, and export a CV for free. When you want saved versions, AI tools, or an application tracker, Pro starts before login.

1

Build the CV

Enter personal details, experience, education, skills, languages, and additional proof. The editor gives structure so users do not start from a blank page.

2

Preview and export

Switch templates, adjust design controls, inspect the A4 preview, and export the finished CV as a PDF. This Basic workflow is free.

3

Upgrade for Pro

Pro unlocks login access, saved CV versions, AI Judge, AI tailoring, AI application writing, and the application tracker.

Why login comes after pricing

Basic does not need login

The free simulator is designed for immediate use. Asking for an account before someone can write or export a CV would slow down the core workflow, so Basic stays open.

Pro needs an active subscription

Saved work, AI calls, and tracking belong to a paid account. That is why the product explains pricing first and only unlocks the logged-in workspace when the subscription is active.

The full workflow

Folio CV starts with the document because that is what users need first. The account layer is added only when the user wants the product to remember work, generate AI output, or manage applications across a longer search.

Draft the base CV

The user fills structured sections instead of fighting a blank page. Personal details, work experience, education, skills, languages, and extra proof become one reusable profile.

Choose a layout and export

The same content can be shown in modern, classic, compact, grid, and other formats. The live preview helps the user check spacing and export the final document as a PDF.

Upgrade only when the job search grows

Pro becomes useful when the user wants role-specific versions, AI judgment, AI tailoring, cover letters, and an application pipeline.

What the user sees

If the user clicks a free action, the editor opens immediately. If the user clicks a Pro action, the app explains pricing and asks for a plan first. The app should not show an email field before that decision.
